# Модель вероятности дефолта эмитентов облигаций РФ (PD на 6 месяцев)

Инструмент инвестиционных рекомендаций: по отчётности, котировкам облигаций и (опционально)
рейтингам оценивает вероятность дефолта эмитента в ближайшие 6 месяцев, сравнивает MARS с моделью
Альтмана и предлагает долю капитала.

## Быстрый старт

```bash
pip install -r requirements.txt
python collect_moex.py      # ~30–60 мин: эмитенты, облигации, дневные котировки с MOEX
python collect_girbo.py     # ~15–30 мин: годовая РСБУ из ГИР БО ФНС
python build_dataset.py     # панель «компания × квартал» + целевая переменная
python train.py             # обучение и сравнение моделей, отчёт в models/report.txt
streamlit run app.py        # интерфейс в браузере
```
Или всё сразу: `run_all.bat` (Windows) / `bash run_all.sh` (Linux/macOS).
Повторный запуск сборщиков докачивает только новое.

## Целевая переменная

Дата среза t — конец каждого квартала (плюс «сегодняшний» срез по последним торгам).
**y = 1, если у эмитента в интервале (t, t + 182 дня] был дефолт**, иначе 0.
Режим `TARGET_MODE` в `config.py`:
`broad` — любой технический или реальный дефолт (по умолчанию: при нём Самолёт с техдефолтами
в мае и сентябре 2026 года — дефолтный случай); `strict` — только реальный дефолт.

Без заглядывания в будущее:
* годовая РСБУ за год Y доступна модели только с 1 апреля Y+1;
* рыночные признаки — только по сделкам до t;
* строки, где окно t + 6 мес. ещё не закончилось, в обучение и тест не входят — по ним только прогноз;
* после реального дефолта строки эмитента исключаются.

## Признаки

* **Коэффициенты РСБУ:** текущая, быстрая, абсолютная ликвидность; доля собственного капитала
  (достаточность капитала); долг/активы; доля краткосрочного долга; ROA; рентабельность EBIT;
  покрытие процентов; чистый долг/EBIT; размер; отрицательный капитал; X1–X4 Альтмана.
* **Динамика за год:** изменения доли капитала, ликвидности, долговой нагрузки, ROA,
  покрытия процентов; рост выручки и активов.
* **Рынок:** минимальная и медианная цена облигаций, максимальная и медианная доходность,
  спред к медиане рынка, изменение цены и волатильность за 3 месяца, оборот.
* **Рейтинг** (если заполнен `ratings_manual.csv`): худший действующий рейтинг (1 = AAA … 22 = D)
  и его изменение за 6 месяцев.
* **История:** были ли техдефолты за последние 12 месяцев.

## Модели

1. **Altman Z'' (классика)** — версия для развивающихся рынков (1995):
   Z'' = 3,25 + 6,56·X1 + 3,26·X2 + 6,72·X3 + 1,05·X4. Зоны: > 5,85 — безопасная, 4,15–5,85 — серая,
   < 4,15 — бедствие. В вероятность переводится логит-калибровкой на обучающей выборке.
2. **Altman-логит** — те же X1–X4, но веса переоценены на российских данных.
3. **MARS (отчётность)** — только РСБУ и динамика.
4. **MARS (полная)** — плюс рынок, рейтинги и история.

**MARS** (Multivariate Adaptive Regression Splines, Friedman 1991) — модель из кусочно-линейных
функций вида max(0, x − t). Сама находит пороги: например, риск резко растёт, когда долг/активы
выше 0,55. Своя реализация в `mars.py`: прямой проход, обратный отбор по GCV, логит сверху.
Библиотека py-earth не используется: она заброшена и не ставится на новый Python.

**Проверка:** out-of-time — обучение на срезах до 31.12.2024, тест на срезах с 2025 года;
**Самолёт целиком в тесте**. Метрики: ROC AUC, Gini, KS, PR AUC, Brier; бутстрэп-интервал для разницы
AUC «MARS − Альтман»; график калибровки.

## Интерфейс (`streamlit run app.py`)

* **Облигация / компания** — выбор выпуска (фильтр по отрасли), PD по всем моделям, Z'' и зона,
  динамика PD с отметками дефолтов, котировки, признаки, разложение прогноза MARS по базисным функциям,
  рекомендация и доля капитала.
* **Скринер** — все компании с PD, сортировкой, фильтрами и сравнением динамики.
* **MARS vs Альтман** — метрики, ROC-кривые, калибровка, уравнения моделей.
* **Своя отчётность** — ввод строк РСБУ (или подстановка из базы) → PD по всем моделям.

**Доля капитала** — половина критерия Келли для бинарного исхода за 6 месяцев: выигрыш — доходность
к погашению сверх безрисковой, проигрыш — LGD. Ограничение — 10% на эмитента, при PD ≥ 50% вложение
нулевое. Параметры `LGD`, `RISK_FREE_ANNUAL` и `MAX_WEIGHT` задаются в `config.py`
(безрисковую ставку обновите на актуальную).

## Ограничения (стоит упомянуть в работе)

* **Квартальная отчётность.** Бесплатного API нет: ГИР БО даёт только годовую РСБУ. Поэтому срезы
  квартальные, финансовые признаки обновляются раз в год, а котировки — каждый квартал.
  Квартальные цифры добавляются в `financials_manual.csv`.
* **РСБУ холдингов.** У Самолёта, ЛСР, ПИКа головная компания — холдинг, и её РСБУ плохо отражает
  группу. Для них лучше внести консолидированную МСФО в `financials_manual.csv`.
  Признаки по котировкам эту проблему частично снимают.
* **Реестр дефолтов** собран по агрегатору. Даты стоит сверить с раскрытием НРД/MOEX и дополнить
  2020–2023 годами — так в обучении будет больше дефолтов.
* **Мало дефолтов в обучении** (десятки) — поэтому MARS аддитивный (без взаимодействий), с ограничением
  числа функций и регуляризацией. Если `train.py` пишет, что дефолтов меньше 5, сдвиньте `TRAIN_END`.
* Банки и страховщики не включены: у них другие формы отчётности.

`tests/make_fake_raw.py` генерирует синтетические данные только для проверки кода — для выводов они
не годятся.
